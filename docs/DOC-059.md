# 1. Objective

Define the Workflow Runtime.

The Workflow Runtime is the runtime orchestrator responsible for coordinating the execution of an entire AI DevOS workflow.

It receives a Project and Workflow, determines the current stage, invokes the Agent Runtime, invokes the Reviewer, processes the review result, updates workflow state, and continues until completion.

The Workflow Runtime never executes LLMs directly.

The Workflow Runtime never builds prompts.

The Workflow Runtime never creates agents.

It orchestrates the complete lifecycle.

Exactly one active stage.

Exactly one active agent.

Exactly one review per stage.

Never execute multiple stages simultaneously.
