# 1. Objective

Define the Kernel Context.

The Kernel Context is the immutable runtime context distributed throughout AI DevOS.

It is constructed from the Kernel Session and exposes only the information required by downstream runtime components.

All runtime components and agents receive a Kernel Context rather than directly accessing the Kernel Session.

The Kernel Context contains no business logic.

It is a read-only runtime state object.
