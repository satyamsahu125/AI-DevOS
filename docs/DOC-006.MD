# DOC-006 — Shared Package

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Shared

---

# 1. Objective

Implement the Shared package.

The Shared package provides the common data contracts used by every package in AI DevOS.

The package contains only reusable data structures.

It shall never contain business logic.

---

# 2. Scope

The Shared package is responsible for:

- Enumerations
- Data Transfer Objects (DTOs)
- Shared Models
- Shared Types
- Value Objects

The Shared package is NOT responsible for:

- Workflow execution
- Memory management
- Context generation
- Session lifecycle
- Project lifecycle
- Artifact storage
- Agent execution
- Prompt generation
- LLM communication

---

# 3. Package Overview

The Shared package is the lowest dependency layer of the system.

Every package may import Shared.

Shared may never import any application package.

Architecture

                    Shared
                       ▲
                       │
 ┌────────────────────────────────────────────┐
 │                                            │
Workflow     Context     Memory     Execution
Project      Review      Session    Agents
Workspace    Artifact    LLM

Responsibilities

• Define reusable data contracts

• Define shared enumerations

• Define DTOs

• Standardize package communication

Must Never

• Execute business logic

• Read files

• Write files

• Call services

• Call LLM

• Modify memory

• Execute workflow
