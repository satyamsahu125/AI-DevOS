# DOC-017 — Project Package

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Project

---

# 1. Objective

Implement the Project package.

The Project package is the entry point of AI DevOS.

It is responsible for creating a new project and initializing every required subsystem before workflow execution begins.

The Project package never executes engineering stages.

The Project package never communicates with LLM providers.

---

# 2. Scope

The Project package is responsible for

• Creating projects

• Creating workspace

• Initializing project memory

• Creating workflow

• Starting workflow

• Loading existing projects

• Returning project information

The Project package is NOT responsible for

• Workflow execution

• Agent execution

• Review

• Memory updates

• Artifact generation

####################################################################
###################### IMPLEMENTATION RULES ########################

1. ProjectManager is the only public API.

2. ProjectRepository owns project persistence.

3. ProjectInitializer initializes required packages.

4. ProjectManager never executes workflow stages.

5. ProjectManager never communicates with LLM providers.

6. Project initialization is deterministic.

7. Initialization stops immediately on failure.
