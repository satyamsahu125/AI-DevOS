# DOC-039 — Reviewer Execution

Version: 1.0

Status: Final

---

# 1. Objective

Define the complete implementation contract for the Reviewer.

The Reviewer is responsible for validating the output generated by an engineering agent.

The Reviewer never creates artifacts.

The Reviewer never edits artifacts.

The Reviewer never executes LLM providers directly.

The Reviewer only validates the submitted artifact and returns a review decision.

---

# 2. Scope

This document defines:

- Reviewer
- Review execution
- Review result
- Review rules
- Retry decision
- Approval decision

This document does NOT define:

- Workflow transitions
- Memory updates
- Agent execution
- Artifact generation
- LLM providers
