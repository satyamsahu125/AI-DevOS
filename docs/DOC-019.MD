# DOC-019 — Shared Enums

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Shared / Enums

---

# 1. Objective

Implement all system-wide enumerations.

Every enumeration represents a finite set of valid values.

Enums eliminate magic strings and standardize communication across all packages.

Enums contain no business logic.

---

# 2. Scope

The Enums package is responsible for

• Workflow Stages

• Session States

• Workflow States

• Review Decisions

• Artifact Types

• Agent Types

• Memory Types

• Provider Types

The Enums package is NOT responsible for

• Business Logic

• Validation

• Workflow

• Execution

---

# 12. Implementation Rules

1. Every enum inherits from str and Enum.

2. Enum values use UPPER_CASE.

3. No methods.

4. No properties.

5. No business logic.

6. Never import application packages.

7. Enums are immutable.

---

# 13. Validation Checklist

✓ All enums implemented

✓ No business logic

✓ No application imports

✓ Package compiles independently

✓ No duplicate values

---

# 14. Exit Criteria

The Enums package is complete when

• Every system constant is represented by an enum.

• No magic strings remain in the application.

• Every package references enums instead of literal values.
