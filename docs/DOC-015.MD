# DOC-015 — Execution Package

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Execution

---

# 1. Objective

Implement the Execution package.

The Execution package is responsible for executing one engineering stage.

Execution begins after Workflow requests a stage.

Execution ends after an artifact has been produced.

Execution never decides workflow progression.

Execution never stores memory.

Execution never approves artifacts.

---

# 2. Scope

The Execution package is responsible for

• Loading Session

• Building Context

• Loading Agent

• Executing Agent

• Returning Artifact

• Returning Execution Result

The Execution package is NOT responsible for

• Workflow

• Memory

• Review

• Project

• Artifact Storage

• Retry Decisions

####################################################################
###################### IMPLEMENTATION RULES ########################

1. ExecutionManager is the only public API.

2. ExecutionEngine is internal.

3. ExecutionPipeline is internal.

4. Execution executes exactly one stage.

5. Execution returns exactly one artifact.

6. Execution never reviews artifacts.

7. Execution never updates memory.

8. Execution never decides the next stage.
