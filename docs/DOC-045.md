# DOC-045 — Backend Developer Agent

Version: 1.0

Status: Final

---

# 1. Objective

Define the complete implementation contract for the Backend Developer Agent.

The Backend Developer Agent is responsible for generating backend implementation code from the approved Architecture Artifact.

It consumes the approved Architecture Specification and produces backend source code artifacts.

The Backend Developer Agent must never:

- Modify architecture
- Execute workflow
- Review artifacts
- Update memory
- Execute other agents

It only generates backend code.

---

# 2. Scope

This document defines:

- BackendDeveloperAgent
- Backend code generation
- Prompt execution
- LLM execution
- Backend artifact generation
- Backend artifact persistence

This document does NOT define:

- Frontend generation
- QA generation
- DevOps generation
- Workflow transitions
