# DOC-048 — DevOps Agent

Version: 1.0

Status: Final

---

# 1. Objective

Define the complete implementation contract for the DevOps Agent.

The DevOps Agent is responsible for generating deployment, infrastructure, CI/CD, containerization, monitoring, and operational artifacts from the approved Architecture Specification and implementation artifacts.

The DevOps Agent is the final engineering agent before workflow completion.

The DevOps Agent must never:

- Modify implementation code
- Modify architecture
- Execute workflow
- Update memory
- Execute other agents

It only generates deployment and operational artifacts.

---

# 2. Scope

This document defines:

- DevOpsAgent
- Infrastructure generation
- CI/CD generation
- Deployment generation
- Prompt execution
- Artifact generation

This document does NOT define:

- Backend implementation
- Frontend implementation
- QA validation
- Workflow transitions
