# 5. Rules

1. Never skip phases.

2. Never implement files out of dependency order.

3. Never modify completed phases unless required.

4. Every package must compile before continuing.

5. Never bypass public managers.

6. Never introduce circular dependencies.

7. Never create undocumented files.

8. Never invent constructors.

9. Never invent methods.

10. Documentation is the single source of truth.

---

# 6. Final Acceptance Criteria

The implementation is complete only when:

✓ The application starts successfully.

✓ A project can be created.

✓ A workspace is created automatically.

✓ Project memory is initialized.

✓ A workflow is created.

✓ Product Owner executes.

✓ Reviewer validates the artifact.

✓ Approved artifacts update project memory.

✓ Workflow advances to the next stage.

✓ No undocumented components exist.

✓ No circular dependencies exist.

✓ Every package follows its implementation contract.
