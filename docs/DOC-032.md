# DOC-032 — LLM Package

Version: 1.0

Status: Final

---

# 1. Objective

Define the complete implementation contract for the LLM Package.

The LLM Package is responsible for providing a unified interface between AI DevOS and every supported Large Language Model provider.

The package owns request creation, provider selection, execution, response parsing, health checking, and configuration.

It must never contain workflow logic, prompt logic, business logic, or memory management.

---

# 2. Scope

This document defines:

- LLM Package
- LLM Manager
- Provider Factory
- Request DTO
- Response DTO
- Provider Interface
- Configuration
- Provider Registry

This document does NOT define:

- Ollama implementation
- Prompt Builder
- Product Owner
- Workflow
- Execution Engine

Those are documented separately.

---

# 3. Package Overview

Responsibilities

✓ Build LLM request

✓ Execute provider

# 12. Implementation Rules

One provider per request.

Manager owns provider.

Providers never know workflow.

Providers never know agents.

Providers never build prompts.

Manager never parses prompts.

Manager only routes requests.
