# DOC-020 — Shared Models

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Shared / Models

---

# 1. Objective

Implement every core domain model shared across the system.

Models represent business entities.

Models contain data only.

Models never execute business logic.

Models never communicate with external packages.

---

# 2. Scope

The Models package is responsible for

• Project

• Workflow

• Stage Session

• Stage Artifact

• Review

• Memory Entry

Models are NOT responsible for

• Validation

• Persistence

• Business Logic

• Workflow

• Execution

---

---

# 12. Implementation Rules

1. Every model uses @dataclass(slots=True).

2. No custom constructor.

3. No business logic.

4. No validation logic.

5. No persistence logic.

6. No helper methods.

7. Models represent entities only.

8. Models must remain immutable after creation.

---

# 13. Validation Checklist

✓ All models implemented

✓ Dataclasses only

✓ No business logic

✓ No application imports

✓ Package compiles independently

---

# 14. Exit Criteria

The Models package is complete when

• Every business entity has a corresponding model.

• Models are shared across packages.

• No package duplicates entity definitions.

• Models remain simple immutable data structures.
