# DOC-011 — Context Package

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Context

---

# 1. Objective

Implement the Context package.

The Context package is responsible for constructing the complete execution context consumed by every AI agent.

The Context package never owns memory.

The Context package never executes workflow.

The Context package only assembles data from other packages.

---

# 2. Scope

The Context package is responsible for

• Building AgentContext

• Loading approved artifacts

• Loading Project Memory

• Loading Runtime Memory

• Loading Workspace

• Loading Review History

• Context trimming

The Context package is NOT responsible for

• Workflow

• Memory ownership

• Artifact persistence

• Review execution

• LLM execution
