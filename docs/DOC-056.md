# 1. Objective

Define the Agent Factory implementation.

The Agent Factory is responsible for constructing and resolving agent instances for every workflow stage.

The Agent Factory receives a Stage and returns the correct initialized Agent.

The Agent Factory never executes agents.

The Agent Factory never advances workflows.

The Agent Factory never performs review.

It only creates and returns fully initialized agent instances.

# 23. Implementation Rules

Exactly one AgentFactory.

One Stage maps to one Agent.

Agent construction must be deterministic.

Dependencies resolved only via DependencyContainer.

Factory never caches agents.

Factory never executes agents.
