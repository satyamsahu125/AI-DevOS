# DOC-028 — Application Entry Point

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Application Entry Point

---

# 1. Objective

Implement the application entry point.

The entry point is responsible for creating the FastAPI application and connecting it with the AI Kernel.

The entry point contains no business logic.

The entry point is the only module started by Uvicorn.

---

# 2. Scope

The Application Entry Point is responsible for

• Creating FastAPI application

• Bootstrapping AI Kernel

• Registering routers

• Registering exception handlers

• Registering lifecycle events

• Starting application

• Stopping application

The Application Entry Point is NOT responsible for

• Workflow

• Project

• Memory

• Session

• Review

• Execution

• Context

• LLM

# 12. Implementation Rules

1. main.py is the only application entry point.

2. AIKernel is started exactly once.

3. AIKernel is stopped exactly once.

4. FastAPI is created exactly once.

5. Routers are registered before startup completes.

6. Exception handlers are registered before accepting requests.

7. No business logic exists inside main.py.

8. No manager is created inside main.py.

9. All dependencies come from AIKernel.

10. Application lifecycle is deterministic.

---

# 13. Validation Checklist

✓ main.py implemented

✓ AIKernel startup registered

✓ AIKernel shutdown registered

✓ API router registered

✓ Exception handlers registered

✓ FastAPI created

✓ Application starts successfully

✓ Application stops successfully

---

# 14. Exit Criteria

The Application Entry Point is complete when

• Uvicorn can start the application.

• AIKernel initializes successfully.

• FastAPI serves requests.

• Routers are available.

• Shutdown is graceful.

• No business logic exists in main.py.
