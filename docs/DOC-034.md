# DOC-034 — Prompt Package

Version: 1.0

Status: Final

---

# 1. Objective

Define the complete implementation contract for the Prompt Package.

The Prompt Package is responsible for converting an AgentContext into a complete LLMRequest.

It owns prompt templates, rendering, variable substitution, validation, and prompt assembly.

The Prompt Package never communicates with the LLM.

The Prompt Package never executes workflow logic.

The Prompt Package never stores artifacts.

It only builds prompts.

---

# 2. Scope

This document defines:

- Prompt Builder
- Prompt Template
- Prompt Renderer
- Prompt Validator
- Prompt Context Mapping

# 12. Implementation Rules

PromptBuilder owns prompt creation.

PromptRenderer owns rendering.

PromptValidator owns validation.

Templates contain no executable logic.

No prompt execution.

No workflow dependency.

No artifact dependency.

No memory dependency.

Never call the LLM.

Always return LLMRequest.
