# DOC-047 — QA Agent

Version: 1.0

Status: Final

---

# 1. Objective

Define the complete implementation contract for the QA Agent.

The QA Agent is responsible for validating the generated implementation artifacts against the approved Requirements Specification and Architecture Specification.

The QA Agent performs static quality verification and generates QA deliverables.

The QA Agent must never:

- Modify source code
- Modify architecture
- Execute workflow
- Update memory
- Execute other agents

It only validates implementation and generates QA artifacts.

---

# 2. Scope

This document defines:

- QAAgent
- Quality validation
- Prompt execution
- LLM execution
- QA artifact generation
- QA report persistence

This document does NOT define:

- Backend generation
- Frontend generation
- DevOps generation
- Workflow transitions
