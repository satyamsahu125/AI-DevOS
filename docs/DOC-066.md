# 1. Objective

Define the Service Registry.

The Service Registry is responsible for maintaining the authoritative registry of every service available in AI DevOS.

The Service Registry contains service metadata only.

It never creates service instances.

It never resolves dependencies.

It never owns runtime objects.

Those responsibilities belong exclusively to the Dependency Injection Container.
