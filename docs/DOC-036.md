# DOC-036 — Product Owner Agent

Version: 1.0

Status: Final

---

# 1. Objective

Define the implementation contract for the Product Owner Agent.

The Product Owner Agent is responsible for generating the initial project requirements using an LLM.

It receives an AgentContext, builds a Product Owner prompt, executes the LLM through the LLM Manager, generates a StageArtifact, stores the artifact, and returns it to the Execution Engine.

The Product Owner Agent must never know anything about workflow transitions, review logic, memory updates, or other agents.
