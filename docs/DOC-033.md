# DOC-033 — Ollama Provider

Version: 1.0

Status: Final

---

# 1. Objective

Define the complete implementation contract for the Ollama Provider.

The Ollama Provider is responsible for communicating with a local Ollama server.

It translates an LLMRequest into an HTTP request, executes it, validates the response, and returns an LLMResponse.

The provider must never know anything about:

- Workflow
- Agent
- Prompt Builder
- Memory
- Artifacts
- Review

It only communicates with Ollama.

---

# 2. Scope

This document defines:

- OllamaProvider

# 12. Implementation Rules

One request per execution.

Never cache responses.

Never store prompts.

Never modify prompts.

Never retry forever.

Never swallow exceptions.

Always return LLMResponse.

Never expose raw HTTP response.

Never expose requests.Response.
