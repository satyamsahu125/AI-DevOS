Version: 1.0

---

# 1. Objective

Define the Agent Runtime.

The Agent Runtime is responsible for executing one workflow stage.

It receives the current Workflow State and AgentContext, resolves the correct Agent through the Agent Factory, executes the Agent, validates the produced artifact, and returns the execution result.

The Agent Runtime never decides workflow transitions.

The Agent Runtime never retries execution.

The Agent Runtime never reviews artifacts.

The Agent Runtime only coordinates a single agent execution.
