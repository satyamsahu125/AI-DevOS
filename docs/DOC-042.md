# DOC-042 — Architect Agent

Version: 1.0

Status: Final

---

# 1. Objective

Define the implementation contract for the Architect Agent.

The Architect Agent is responsible for transforming the approved Product Requirements Specification into the complete technical architecture of the project.

The Architect Agent produces the Architecture Specification that becomes the foundation for all implementation agents.

The Architect Agent must never:

- Generate source code
- Modify workflow
- Update memory
- Review artifacts
- Execute other agents

It only produces the technical architecture.

---

# 2. Scope

This document defines:

- ArchitectAgent
- Architecture generation
- Prompt execution
- LLM execution
- Architecture artifact generation
- Artifact persistence

This document does NOT define:

- Backend implementation
- Frontend implementation
- QA implementation
- DevOps implementation
- Workflow transitions
