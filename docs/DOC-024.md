# DOC-024 — Shared Constants

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Shared / Constants

---

# 1. Objective

Implement every application-wide constant used across the system.

Constants define immutable configuration values used by multiple packages.

Constants eliminate duplicated literals.

Constants never contain business logic.

Constants never change during runtime.

---

# 2. Scope

The Constants package is responsible for

• Retry limits

• Context limits

• Session limits

• Workflow limits

• Memory limits

• Artifact limits

• LLM defaults

• Workspace defaults

Constants are NOT responsible for

• Runtime configuration

• Environment variables

• Feature flags

• Business logic

---

# 3. Package Overview

Application

Every package may read constants.

No package may modify constants.

# 12. Implementation Rules

1. Constants use UPPER_CASE naming.

2. No functions.

3. No classes.

4. No mutable objects.

5. No application imports.

6. No runtime modifications.

7. Constants are grouped by domain.

---

# 13. Validation Checklist

✓ All constant files created

✓ No mutable values

✓ No business logic

✓ No application imports

✓ Package compiles independently

---

# 14. Exit Criteria

The Constants package is complete when

• Every reusable literal exists exactly once.

• No magic numbers remain in the application.

• Constants are grouped by domain.

• The package contains only immutable values.
