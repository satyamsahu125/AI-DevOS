# DOC-043 — Architect Prompt Builder

Version: 1.0

Status: Final

---

# 1. Objective

Define the complete implementation contract for the Architect Prompt Builder.

The Architect Prompt Builder transforms an AgentContext into an LLMRequest specifically for the Architect Agent.

It is responsible for assembling all architectural context required by the LLM.

It never executes the LLM.

It never generates artifacts.

It never performs architecture decisions.

It only builds prompts.

---

# 2. Scope

This document defines:

- ArchitectPromptBuilder
- Architecture prompt generation
- Variable extraction
- Template rendering
- Prompt validation
- LLMRequest creation

This document does NOT define:

- Architect Agent
- LLM Manager
- Workflow
- Artifact generation
- Memory updates
