# DOC-016 — Workflow Package

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Workflow

---

# 1. Objective

Implement the Workflow package.

The Workflow package owns the complete software engineering lifecycle.

It determines:

• execution order

• stage dependencies

• retry logic

• approval flow

• session transitions

• workflow completion

Workflow never executes AI.

Workflow delegates execution to the Execution package.

---

# 2. Scope

The Workflow package is responsible for

• Creating workflows

• Starting workflows

• Executing stages

• Dependency validation

• Session coordination

• Review coordination

• Retry coordination

• Workflow completion

• Workflow failure

Workflow is NOT responsible for

• Running agents

• Memory storage

• Context creation

• LLM execution

• Artifact generation

####################################################################
###################### IMPLEMENTATION RULES ########################

1. WorkflowManager is the only public API.

2. Workflow owns orchestration.

3. Execution owns execution.

4. Review owns approval.

5. Memory owns knowledge.

6. Session owns stage lifecycle.

7. Workflow never skips dependencies.

8. Workflow never updates memory before approval.

9. Workflow never exposes draft artifacts.

10. Workflow always creates exactly one session per stage.
