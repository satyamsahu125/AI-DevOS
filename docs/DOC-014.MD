# DOC-014 — Agents Package

Version: 1.0

Status: Draft

Phase: Product Owner MVP

Package: Agents

---

# 1. Objective

Implement the Agents package.

The Agents package contains every engineering agent used by the AI DevOS workflow.

Agents never communicate directly with each other.

Agents are completely stateless.

Every execution receives exactly one AgentContext and produces exactly one StageArtifact.

---

# 2. Scope

The Agents package is responsible for

• Product Owner

• Reviewer

• Architect

• Planner

• Backend Developer

• Frontend Developer

• Agent Lifecycle

• Prompt Execution

The Agents package is NOT responsible for

• Workflow

• Memory

• Context Building

• Session

• Artifact Storage

• Review Storage

• Project Creation

####################################################################
###################### IMPLEMENTATION RULES ########################

1. Every agent inherits BaseAgent.

2. Agents are stateless.

3. Every execution receives one AgentContext.

4. Every execution returns one StageArtifact.

5. Agents never update memory.

6. Agents never execute workflow.

7. Agents never communicate with each other.

8. AgentRegistry is the only lookup mechanism.
