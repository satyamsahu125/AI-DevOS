# 1. Objective

Define the Kernel Session.

The Kernel Session represents one autonomous execution lifecycle inside AI DevOS.

Every project execution owns exactly one Kernel Session.

The Kernel Session stores all runtime state required to execute, pause, resume, recover, and terminate a project execution.

The Kernel Session owns no business logic.

It is a runtime state container only.
