# DOC-035 — Product Owner Prompt Builder

Version: 1.0

Status: Final

---

# 1. Objective

Define the implementation contract for the Product Owner Prompt Builder.

The Product Owner Prompt Builder is responsible for transforming an AgentContext into a fully prepared LLMRequest for the Product Owner Agent.

It owns:

- Variable extraction
- Prompt template loading
- Prompt rendering
- Prompt validation
- Request construction

It never executes the LLM.

It never executes the Product Owner.

It never creates artifacts.

It only builds one Product Owner prompt.

---
